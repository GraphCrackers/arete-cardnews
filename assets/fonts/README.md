폰트 파일(.otf/.ttf/.woff2)을 이 폴더에 넣고, 파일명 배열을 담은 index.json을 같이 둡니다.

    ["PretendardVariable.woff2", "GmarketSansBold.otf", "SUIT-Medium.otf"]

index.json은 에디터에서 폰트 폴더를 한 번 불러온 뒤
오른쪽 패널의 "폰트 목록 index.json 내보내기" 버튼으로 만들 수 있습니다.

파일명에 gmarket / pretendard / paperlogy / suit / mbk 중 하나가 들어가야 인식됩니다.
굵기는 파일명의 숫자(700) 또는 단어(Bold, ExtraLight)로 판별합니다.

주의: 공개 저장소에 폰트를 올리는 것은 재배포에 해당하므로 각 폰트의 라이선스를 확인하세요.
