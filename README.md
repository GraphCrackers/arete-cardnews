# ARETE 카드뉴스 편집기

카드뉴스의 글·사진·색상을 수정하고, 팀원에게 공유하거나 이미지로 저장하는 도구입니다.

👉 **[카드뉴스 편집기 열기](https://graphcrackers.github.io/arete-cardnews/)**

> **시작하기 전에 꼭!**
>
> **편집기에 들어가면 먼저 GitHub에 로그인해주세요.** 로그인해야 수정한 내용을 사이트에 반영할 수 있습니다.
>
> **같은 편을 두 사람 이상이 동시에 수정하지 마세요.** 작업 내용이 자동으로 합쳐지지 않습니다. 나중에 게시하는 사람은 게시가 막히고, 수정 내용을 다시 합쳐야 할 수 있어요. 시작 전에 “제가 회복탄력성 편 수정할게요”처럼 담당할 편을 서로 알려주세요.

## 1. 들어가서 먼저 GitHub 로그인하기

1. 위의 **편집기 링크**를 여세요. 처음에 편 목록이 뜨면 작업할 편을 선택하세요.
2. 위쪽 **GitHub 로그인**을 누르고 **본인 계정**으로 로그인하세요.
3. 처음 나오는 승인 화면에서는 **Authorize ARETE Cardnews**를 누르세요.
4. 버튼이 **내 계정명 · 로그아웃**으로 바뀌면 준비 완료입니다.

새로고침하면 다시 로그인해야 합니다. 팀원은 Cloudflare 설정이나 별도 프로그램 설치가 필요 없습니다.

항상 위 링크로 접속해주세요. 컴퓨터의 `index.html` 파일을 직접 열면 로그인이나 글꼴 등 일부 기능이 작동하지 않습니다.

## 2. 카드뉴스 수정하기

**다른 팀원이 같은 편을 작업하고 있지 않은지 먼저 확인하세요.** 다른 편으로 이동하려면 **편 목록**을 누르면 됩니다.

| 하고 싶은 작업 | 방법 |
|---|---|
| 글 수정 | 글자를 두 번 클릭하고 입력 |
| 글·사진 이동 | 클릭해서 끌기 |
| 글자 크기 변경 | 글자를 선택하고 오른쪽 설정에서 변경 |
| 상자 크기 변경 | 모서리 손잡이 끌기 — 글자 크기는 별도 설정 |
| 색·글꼴 변경 | 오른쪽 설정 사용 |
| 카드 추가·복제·삭제·순서 변경 | 왼쪽 카드 목록 사용 |
| 글 강조 | 형광펜은 `==강조할 글==`, 굵게는 `**강조할 글**` |

## 3. 사이트에 반영하기

1. 위쪽 **사이트에 반영**을 누르세요.
2. 공개할 내용을 확인하고 게시하세요.
3. **사이트 반영 완료** 안내가 나올 때까지 기다리세요.

완료되면 다른 팀원도 페이지를 새로고침해서 수정본을 볼 수 있습니다. JSON 파일을 보내거나 GitHub Desktop에서 따로 푸시할 필요가 없습니다.

**화면에서 수정만 하면 다른 사람에게는 보이지 않습니다. 작업이 끝나면 꼭 ‘사이트에 반영’을 눌러주세요.**

## 4. 이미지로 저장하기

- **전체 PNG**: 모든 카드를 이미지로 저장합니다.
- **이 카드 PNG**: 현재 보고 있는 카드만 저장합니다.

저장된 이미지를 인스타그램 등에 올리면 됩니다. 브라우저에서 여러 파일 다운로드 허용을 물으면 허용해주세요.

## 주의사항

> **같은 편은 한 번에 한 사람만 수정해주세요.**
>
> 서로 다른 편을 나눠 작업하는 것이 좋습니다. 다른 팀원이 먼저 게시했다는 안내가 나오면, **새로고침하기 전에 JSON 내보내기로 내 작업을 백업**하세요. 그다음 최신 편을 열고 담당 팀원과 변경 내용을 확인해 합쳐주세요.

- **게시한 내용은 링크를 가진 누구나 볼 수 있습니다.** 공개해도 되는 내용만 올려주세요.
- **사이트에 반영**은 이 GitHub 저장소의 쓰기 권한이 있는 팀원만 사용할 수 있습니다.
- 구석의 **JSON 내보내기 / JSON 불러오기**는 작업 백업·복구용입니다. 평소에는 사용하지 않아도 됩니다.
- 게시에 실패하면 안내 문구를 확인하고, 해결이 어려우면 작업을 JSON으로 백업한 뒤 담당자에게 문의해주세요.
