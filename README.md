# ARETE 카드뉴스 에디터

인스타그램 카드뉴스(1080×1350)를 브라우저에서 만들고 고치는 도구.
**설치할 것도, 가입할 것도 없다. 링크만 열면 된다.**

---

## 팀원용 — 카드 고치기

### 1. 링크를 연다

```
https://<계정>.github.io/<저장소>/?p=inquiry-question
```

`?p=` 뒤가 편 이름이다. 그냥 주소만 열면 편 목록이 나온다.

> ⚠️ **파일을 내려받아 더블클릭하면 안 된다.** 글꼴이 깨진다.
> 브라우저가 `file://` 로 열린 페이지의 글꼴 파일 읽기를 막기 때문이다. 반드시 링크로 연다.

### 2. 고친다

| 하고 싶은 것 | 방법 |
|---|---|
| 글자 고치기 | 글자를 **두 번 클릭** → 바로 타이핑 |
| 옮기기 | 끌어다 놓기. 방향키는 1px, Shift+방향키는 10px |
| 크기 | 모서리 손잡이를 끈다 (**상자만** 커진다) |
| **글자 크기** | **⌘ + ↑ ↓** (Shift 같이 누르면 10씩) |
| 형광펜 | 글자를 `==이렇게==` 감싼다 |
| 굵게 | `**이렇게**` |
| 카드 추가·복제·순서 | 왼쪽 목록 아래 버튼 |

색과 글꼴은 오른쪽 패널에서 바꾼다. **카드마다 색을 따로 칠하지 않는다** — 팔레트를 바꾸면 전부 따라온다.

### 3. 저장한다 — 자동 저장이 아니다

정적 페이지라 서버에 저장되지 않는다. **작업이 끝나면 반드시:**

1. 위쪽 **JSON 내보내기** 를 누른다 → `.json` 파일이 받아진다
2. 그 파일을 대표에게 보낸다

브라우저에 임시로는 남아 있어서 실수로 닫아도 다시 열면 이어서 할 수 있다.
하지만 **다른 사람에게 전달되려면 JSON 을 내보내야 한다.**

### 4. 이미지로 뽑기

**전체 PNG** 를 누르면 카드가 장마다 PNG 로 받아진다. 인스타에 올릴 그 파일이다.

> **두 사람이 같은 편을 동시에 고치면 나중에 보낸 것이 앞의 것을 덮는다.**
> 누가 어느 편을 잡을지 먼저 정하고 시작한다.

---

## 대표용 — 새 편 올리기

1. `projects/<편이름>.json` 을 추가한다
2. `projects/index.json` 목록에 한 줄 넣는다

```json
[
  { "id": "inquiry-question", "title": "탐구 질문 좁히기" }
]
```

3. 커밋하고 푸시한다. 1~2분 뒤 링크에 반영된다

**문구를 쓸 때는 `voice.md` 를 먼저 읽는다.** 초안을 AI에게 시킬 때도 그 파일을 같이 준다.

---

## 배포 (한 번만)

GitHub 에서 **공개** 저장소를 만들고 이 폴더를 올린 뒤,
`Settings > Pages > Source: Deploy from a branch > main / (root)`.

무료 플랜은 공개 저장소에서만 Pages 가 된다.
**배포된 페이지는 누구나 볼 수 있다. 미공개 기획이 담긴 JSON 은 `projects/` 에 두지 않는다.**

---

## 구조

```
index.html          에디터 본체. 이 파일 하나가 프로그램 전부
voice.md            문구 쓸 때 지키는 문체 규칙
projects/
  index.json        편 목록
  <편이름>.json      카드뉴스 한 편
assets/
  fonts/            글꼴 6종 + 라이선스 (LICENSES.md 먼저 읽을 것)
  img/              배경·본문 이미지
reference/samples/  기존 카드뉴스 10장 (레이아웃 참고용)
```

작업 맥락과 설계 배경은 `HANDOFF.md`.

## 글꼴

Pretendard · Paperlogy · SUIT · Gmarket Sans · Noto Serif KR · Cormorant Garamond.
전부 재배포가 허용된 것만 넣었다. **MBK 는 재배포 금지라 없다** — 쓰려면 각자 맥에 설치한 뒤
「폰트 폴더 불러오기」로 그때그때 올린다. 자세한 것은 `assets/fonts/LICENSES.md`.
